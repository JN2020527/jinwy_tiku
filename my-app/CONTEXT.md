# 题库后台

面向运营的内容生产与标签管理后台，为前台题库、平台资源库与教学计划提供数据基础。

## 资源资产

**资产中心**：按学科查看和维护学案、作业、Word、PPT、音频、视频资产的统一目录。列表只展示名称、类型、草稿/正式状态、原文件名、更新时间和操作；资源节点不是资产固定归属或列表筛选字段。 _Avoid_: 资源中心、版本目录、资源树资产清单

**资源树与挂载关系**：资源树仍是每学科独立维护的资源节点结构，只有末级节点可以挂载正式资源。资源资产本体、资源节点和挂载关系是三个不同对象；本次资产管理不新增、移除或调整挂载关系。资源树页面保持既有验收行为。 _Avoid_: 资产归属、上传时选择资源节点、把挂载写进资产本体

**资源资产类型**：组合型资产为学案、作业；附件型资产为 Word（`.docx`）、PPT（`.ppt/.pptx`）、音频（`.mp3/.wav`）、视频（`.mp4`）。资产学科和类型创建后不可修改。

**资源资产状态**：学案有草稿、正式两种状态且使用同一 ID，只允许草稿转正式。知识块和附件保存成功后直接正式；作业本期不形成草稿。资源资产没有未上架、已上架、归档、停用、审核、独立发布或版本。 _Avoid_: 修订草稿、待生效版本、历史版本、上架状态

**资产名称**：学案与作业分别在“同一学科 + 同一类型”内唯一，二者可以同名；附件在“同一学科 + 同一附件类型”内唯一，不同附件类型可以同名。冲突时阻止保存，不覆盖也不形成版本。

**成品学案上传**：在资产中心当前学科下上传单个 `.docx`，学科锁定且不二次选择。原型用 fixture 模拟 Word 栏目标记、内容标记、试题型栏目跳过、完整错误列表和富文本拆分；成功后形成学案草稿，拆分结果使用独立页面。

**学案草稿**：只允许编辑或删除已有内容块，不允许新增、移动、排序或改变结构关系。调整自动保存；删除内容后清理空局部结构并重算综合类候选知识点。最终保存原子形成正式学案和新知识块。

**正式学案维护**：先进入只读预览，再显式进入组合编辑器。编辑器维护一级栏目位置、二级分组、三级考点项、四级栏目位置和栏目项；保存更新同一学案 ID，不形成版本，也不修改注册栏目定义或源知识块本体。

**加工作业**：作业是平铺有序的试题引用列表，不使用学案四层栏目结构。编辑从资产中心当前学科空白新建，只选择已发布正式试题；界面中的「作业篮」即已选列表，直接构成作业本体，并非独立中间态，支持同题去重且上限 60 题。作业篮和只读预览按题型自动分组展示，组序取题型首次出现顺序、组内保留平铺顺序；分组不保存为作业对象结构。作业无草稿、保存即正式，正式作业先只读预览再显式编辑，保存更新同一 ID 且不形成版本；引用按试题 ID 动态读取当前内容。作业不进入学案组合编辑器。 _Avoid_: 独立试题篮中间态、持久化分组对象、复制作业、作业版本

**注册栏目**：栏目维护每学科只注册一级、四级。四级必须归属同学科一级；同一学科全部注册栏目名称全局唯一。被学案使用的栏目可改名、排序，禁止改类型和删除；被使用四级还禁止调整一级归属。

**知识树**：资源资产知识树使用 `/preparation/knowledge-tree` 独立数据域；知识块和学案三级考点项只关联或引用末级节点。存在任一关系时，节点不能新增子节点、接收拖入节点而变非末级或删除。试题知识体系 `/tag-system/knowledge` 不受影响。

**知识块**：单一、综合、方法、例题四类知识原子资产，没有名称、草稿或版本。新建时继承并锁定列表当前学科；列表完整展示富文本。被引用时允许修改但需确认影响，关系修改导致既有引用范围失效时阻止；存在引用时禁止删除。

**本次知识范围**：综合类知识块引用项在当前学案实际使用的知识点子集，只能从“源知识块关联且本学案实际涉及的三级考点”交集中选择至少一个，默认全选交集。正式学案编辑只重算引用项范围，不修改源知识块关系。

**附件维护**：附件按扩展名自动识别类型并直接正式；只允许替换同类型文件，替换后资产 ID、名称、学科和关系保持不变。附件没有在线内容编辑或版本历史。

**删除保护**：知识块被学案引用时禁止删除。学案、作业或附件存在资源节点挂载、平台模板或教师任务引用时禁止删除并分别展示数量；系统不自动解除关系或保留占位。

## 教学计划模板

**教学计划模板**：运营按学科预置教学周和教学任务顺序的后台配置载体；创建时确定模板名称、总周数与统一的每周平均课时，不配置复习阶段。同一学科内模板名称唯一，同一学科可以同时存在多个已启动模板。 _Avoid_: 教师个人教学计划、复习方案

**模板版本**：同一教学计划模板历次配置形成的内部版本，状态为草稿、已启动、已停用或已归档。同一模板只能有一个当前已启动版本和一个待编辑草稿；已启动版本不可原地编辑，点击编辑时创建或进入草稿版本，原启动版本继续生效。草稿通过完整启动校验后原子替换当前启动版本；校验失败时不影响原启动版本。后台主列表按模板聚合为一行，不直接展示版本号；同时存在已启动版本和草稿时，对外显示“已启动 · 有未发布修改”。主列表只展示最后更新人和更新时间，启动人及启动时间保留在内部记录中。 _Avoid_: 直接覆盖已启动模板、审核版本

**教学任务锚点**：运营在某一教学周选择一个可排期资源节点形成的模板配置项，记录人工指定的最早开始周和周内顺序；任务名称与计划总课时来自资源节点，同一资源节点在一个模板内只能选择一次。系统不会把任务排到锚点之前，但前序任务占用后续周容量时，可以将该任务整体顺延；锚点本身不被改写。锚点可以在草稿中移动或排序，但不保存人工拆分结果。 _Avoid_: 排期片段、独立编辑内容

**排期片段**：系统根据任务锚点、全局任务顺序、建议课时和每周容量计算出的某任务在某周占用的课时。任务跨周时，下一周的续排片段置顶并只读；前序续排占用后续周容量时，后续任务按顺序自动顺延。修改来源任务、顺序或容量后重新计算，不允许直接编辑片段。 _Avoid_: 新教学任务、手工拆分任务

**启动校验**：草稿转为已启动版本前执行的整份校验；模板必须至少有一个任务，所有节点仍有效，且所有任务都能在总周数内排完。前序任务挤占后续任务的锚点周不再视为冲突，系统自动顺延；容量未用满不阻止启动，只展示未分配课时。校验失败的模板仍可保存草稿，且不能停用或替换原启动版本。 _Avoid_: 审核流、保存校验

## 标签体系

**知识点树**：按教材体系或中考体系组织的知识节点树，节点为纯文本分类，通过 `targetType: 'knowledge'` 区分。 _Avoid_: 知识体系（泛指时）

**专题树**：与知识点树并列的独立树，节点为专题分类，通过 `targetType: 'topic'` 区分；与知识点树共用同一套树 CRUD 接口。 _Avoid_: 专题体系

**树模板**：由当前筛选上下文（学科 + 体系）下的知识点树/专题树/资源树导出得到的 Excel 文件，结构为逐级列（级别 1/级别 2/…）；该文件既是树的快照，也是导入的输入格式，导出与模板是同一份文件。 _Avoid_: 导入模板（暗示与导出分离的独立文件）

**树导入（清空重建）**：将树模板解析后，清空当前学科 + 体系下的整棵树并按模板重建的操作；重建前必须先展示导入预览。资源树仅在尚无正式资源且没有教学任务引用时允许清空重建，否则只能在原节点身份上调整结构。 _Avoid_: 增量合并、追加导入、覆盖导入
