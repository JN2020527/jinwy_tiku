# 教学计划模板按周锚定任务并生成不可变启动版本

教学计划模板由运营按学科创建，基础容量由总周数和统一的每周平均课时确定。运营逐周选择复习树末级的可排期资源节点并维护周内顺序；同一节点在一个模板内只能出现一次。人工配置只保存任务的起始周和顺序，系统以 0.5 课时为最小单位，根据节点建议课时自动生成逐周排期片段。任务可以跨越连续多周，续排片段只读；系统不把任务提前填入运营主动留空的周。

草稿中的任务、顺序、容量或节点建议课时变化时，系统重新计算整份排期。重新排期保留后续任务的人工起始周；当前序任务挤占该位置时标记冲突，不静默改写运营配置。冲突或超容量草稿可以保存但不能启动，容量未用满允许启动。

启动产生不可变版本，冻结节点名称、建议课时与排期快照，但任务使用时动态读取节点下当前可用资源。已启动版本不能原地编辑；修改会产生新草稿版本。同一模板只能有一个当前已启动版本，已停用版本重新启动时必须再次执行完整校验。首期不建设独立审核流，以启动人和启动时间作为操作追溯信息。
