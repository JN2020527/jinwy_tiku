# 教学计划模板按周锚定任务并生成不可变启动版本

教学计划模板由运营按学科创建，基础容量由总周数和统一的每周平均课时确定。运营逐周选择复习树末级的可排期资源节点并维护周内顺序；同一节点在一个模板内只能出现一次。人工配置只保存任务的最早开始周和顺序，系统以 0.5 课时为最小单位，根据节点建议课时自动生成逐周排期片段。任务可以跨越连续多周，续排片段只读；系统不把任务提前填入运营主动留空的周。

草稿中的任务、顺序、容量或节点建议课时变化时，系统重新计算整份排期。重新排期保留人工指定的最早开始周；前序任务跨周占用后续容量时，系统按全局任务顺序自动顺延后续任务，不改写人工锚点。只有任务最终超出模板总周数，或存在无效节点、非法课时、重复节点等问题时才标记冲突；冲突草稿可以保存但不能启动，容量未用满允许启动。

启动产生不可变版本，冻结节点名称、建议课时与排期快照，但任务使用时动态读取节点下当前可用资源。已启动版本不能原地编辑；点击编辑时系统创建或进入该模板唯一的草稿版本，原启动版本继续生效。同一模板只能有一个当前已启动版本；新草稿或已停用版本通过完整启动校验后，系统原子替换当前启动版本，校验失败时不改变原启动版本。版本机制只用于内部追溯，后台主列表按模板聚合为一行；存在草稿时使用“有未发布修改”和“发布更新”表达，不向运营暴露 V1、V2。主列表展示最后更新人与更新时间；启动人和启动时间保留在内部记录中。首期不建设独立审核流。
