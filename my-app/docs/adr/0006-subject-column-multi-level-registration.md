# ADR 0006：栏目定义支持多适用层级

## 状态

已接受

## 背景

同一个业务栏目可能出现在学案结构的不同层级，例如“考点”既可能作为二级栏目，也可能作为三级栏目。若按层级复制栏目定义，会产生同名记录、类型与数据来源重复维护，以及跨层级口径漂移。编码方式同样不是某个具体栏目的属性，而是同一学科中某个结构层级的统一展示规则。

## 决策

- 栏目定义在同一学科内保持唯一，一条记录保存名称、类型和数据来源，并通过 `applicableLevels` 关联一个或多个适用层级。
- 栏目在各适用层级中的顺序分别保存；调整一个层级的顺序不影响其他层级。
- 编码规则独立归属“学科 + 层级”，不再保存在栏目定义中；每层可选择不编码或一种受支持的编码样式。
- 学案结构节点继续保存栏目 ID 和自身层级。选择栏目时只展示适用于该层级的栏目；编号按同一直接父节点下的同级顺序重新计算。
- 已被草稿或正式学案引用的层级关联不可取消；栏目存在任意学案引用时不可删除。

## 后果

- 一个栏目可在多个层级复用，无需复制同名栏目。
- 名称、类型和数据来源的修改只维护一处；知识树来源“同学科同层级最多一个”的约束对全部适用层级生效。
- 页面需要提供多选“适用层级”、按层级排序入口和独立的层级编码规则入口。
- 旧的单值 `level`、栏目级编码字段和跨层级父子注册关系不再作为当前模型。
