# 知识点树/专题树导入采用「清空重建 + 预览确认」，而非增量合并

知识点树与专题树当前只能逐条在页面配置，现以 Excel 模板（导出即模板）支持批量导入。导入语义定为：解析模板后清空当前学科 + 体系下的整棵树并按模板重建，落库前先展示导入预览（含错误行标红）供运营确认。

选择清空重建而非增量合并，是因为导入的典型场景是批量初始化（一次倒入某学科的知识体系），重建幂等、不怕重复导、无需设计名称匹配规则；增量合并需要处理"与现有树同名/部分重叠"的复杂语义，与树 CRUD 已有的"同级不可重名"约束冲突时行为难定义。重建的误清空风险由预览确认环节兜底。若未来出现"运营在已有树上追加章节"的真实诉求，可再评估增量模式，届时本决策应被显式重审。
