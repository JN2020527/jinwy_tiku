# 正式资源采用版本、可见状态与默认固定版本引用

> 本 ADR 已被资源资产 V0.3 模型替代，仅保留历史。知识块、学案、作业和附件均不建立版本，也没有上架、归档或停用状态；正式资源是否在前台出现只由挂载关系决定。现行口径见根 `CONTEXT.md`“资源资产”。

资产中心的一行代表一份逻辑资源，资源类型创建后不可修改；附件上传新文件或组合型资源发布修订草稿时产生新版本，新版本确认前不替换当前生效版本，历史版本可重新生效。正式资源具有未上架、已上架、已归档状态：归档停止新展示和新引用但保留历史引用，只有从未被业务引用的资源才能彻底删除。

平台资源库读取当前生效版本；业务对象直接选用正式资源时，默认固定引用选择时的具体版本。教学计划模板不直接选择资源版本，而是选择可排期资源节点：其启动版本冻结节点名称、建议课时与排期，任务使用时仍动态读取节点下当前可用资源。该例外由 ADR-0005 约束，不改变其他资源引用的固定版本语义。

该设计牺牲直接覆盖和硬删除的简单性，以换取历史可追溯、版本回退以及既有业务不被后续资产变更意外篡改，同时允许平台统一维护的备课资源持续更新。
