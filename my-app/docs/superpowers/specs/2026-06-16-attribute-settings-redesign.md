# 属性设置重构设计规格

## 背景

当前属性设置页面把“属性创建”和“属性使用”放在同一套配置里，导致运营在创建属性时需要同时理解上传、打标、前台展示、筛选、必填、字段编码等规则。随着业务规则被澄清，这种自由组合已经超过了当前需要。

新的核心判断是：属性先被定义为一种业务信息，再被不同业务场景引用。创建属性时只回答“这个属性是什么”，使用设置时再回答“这个属性在哪里生效、是否必填、排序如何”。

## 业务规则

属性分为四类，每类属性先明确归属对象和边界：

| 属性类型 | 归属对象 | 主要定义内容 | 不承担的职责 |
| --- | --- | --- | --- |
| 试卷属性 | 试卷整体 | 年份、地区、题源、试卷类型等试卷维度信息 | 不参与试题打标，不展示在试题卡片或试题筛选区 |
| 试题属性 | 单个试题 | 难度、题型、能力、考法等试题维度信息 | 不参与试卷上传，不展示在试卷卡片或试卷筛选区 |
| 知识点属性 | 知识体系节点 | 目标分类、重难点、2025 首次考查等知识节点特征 | 不作为试题筛选项，不维护知识树节点本身 |
| 专题属性 | 专题体系节点 | 考频等专题节点特征 | 不作为试题筛选项，不维护专题树节点本身 |

使用场景按消费位置拆分：

| 使用场景 | 可用属性类型 | 消费位置 | 关键配置 |
| --- | --- | --- | --- |
| 试卷上传 | 试卷属性 | 上传后的试卷信息完善表单 | 启用、必填、顺序 |
| 试卷卡片展示 | 试卷属性 | 试卷列表卡片 | 是否展示、展示顺序 |
| 试卷列表筛选 | 试卷属性 | 试卷列表上方筛选区 | 是否筛选、筛选顺序 |
| 试题打标 | 试题属性 | 下游试题打标表单 | 启用、必填、顺序 |
| 试题卡片展示 | 试题属性 | 试题列表卡片 | 是否展示、展示顺序 |
| 试题列表筛选 | 试题属性 | 试题列表上方筛选区 | 是否筛选、筛选顺序 |
| 知识树节点展示 | 知识点属性 | 知识树或章节树节点旁 | 是否展示、展示顺序 |
| 专题树节点展示 | 专题属性 | 专题树节点旁 | 是否展示、展示顺序 |

试题和试卷存在隶属关系，上传按试卷整体进行，所以试题属性不进入上传环节。打标针对试题进行，所以试卷属性不进入打标环节。前台用途不能只按“展示/筛选”理解，必须先看资源展示方式：成品套卷等页面展示试卷列表，试卷属性一部分伴随试卷列表卡片展示，一部分出现在试卷列表上方筛选区；知识点选题、章节选题是自由选题这种使用形式下的具体功能模块，页面展示或选择单个试题，试题属性一部分伴随试题列表卡片展示，一部分出现在试题列表上方筛选区。知识点属性不作为筛选器，而是作为知识树或章节树节点旁的标识、说明随树展示。

## 设计目标

1. 将属性本体和业务使用配置拆开，降低运营理解成本。
2. 删除无效组合，避免试卷属性参与打标、试题属性参与上传等配置错误。
3. 保留运营真正需要的动作：创建属性、维护枚举值、启停、拖拽排序、配置场景使用。
4. 为后续上传页、打标页、试卷列表、知识点选题、章节选题、知识树、专题树消费属性配置提供清晰的数据结构。

## 非目标

- 不在主流程暴露属性编码、取值字段、字段类型、控件类型。
- 不支持试题属性参与试卷卡片展示、试卷列表筛选、知识树节点展示或专题树节点展示。
- 不支持试卷属性打标。
- 不支持试题属性上传信息完善。
- 不支持试卷属性参与试题卡片展示或试题列表筛选。
- 不支持知识点属性参与上传、打标、试卷卡片展示、试卷列表筛选、试题卡片展示或试题列表筛选。
- 不支持专题属性参与上传、打标、试卷卡片展示、试卷列表筛选、试题卡片展示或试题列表筛选。
- 不拆分前台展示名称和属性名称。前台默认使用属性名称。
- 不为枚举值配置颜色、独立前台名称或独立前台可见性。
- 不把知识点树和专题树的节点维护塞进属性枚举值管理。属性设置只维护节点属性及其枚举值，树节点仍由知识体系和专题体系模块维护。

## 信息架构

属性设置页保留为一个菜单，进入后用两个一级 Tab 承载不同任务：

- 属性定义
- 使用设置

### 属性定义

用于维护属性本体。

字段：

- 属性类型：试卷属性 / 试题属性 / 知识点属性 / 专题属性。
- 属性名称。
- 启用状态。
- 属性排序。
- 枚举值列表。
- 枚举值排序。
- 枚举值启用状态。

行为：

- 新增属性时必须选择属性类型。
- 属性名称是后台管理和前台默认展示共用名称。
- 枚举值以普通文本列表展示，不使用彩色标签。
- 枚举值支持拖拽排序，后台顺序即业务展示顺序。
- 知识点属性和专题属性也在这里维护枚举值，例如目标分类、重难点、考频的可选值。
- 知识点属性值与知识树节点的绑定在知识体系模块完成，专题属性值与专题树节点的绑定在专题体系模块完成。
- 停用属性后，该属性不再出现在使用设置和消费端。

### 使用设置

用于配置属性在哪些业务场景中生效。

按场景拆成八组：

1. 试卷上传
   - 可选择启用的试卷属性。
   - 支持设置是否必填。
   - 支持拖拽排序，决定上传表单字段顺序。

2. 试卷卡片展示
   - 可选择启用的试卷属性。
   - 支持拖拽排序，决定试卷列表卡片上的属性展示顺序。
   - 展示文案默认使用属性名称。
   - 成品套卷等试卷列表共同消费该配置。

3. 试卷列表筛选
   - 可选择启用的试卷属性作为筛选项。
   - 支持拖拽排序，决定试卷列表上方筛选区的属性筛选顺序。
   - 筛选项文案默认使用属性名称。
   - 成品套卷等试卷列表共同消费该配置。

4. 试题打标
   - 可选择启用的试题属性。
   - 支持设置是否必填。
   - 支持拖拽排序，决定打标表单字段顺序。

5. 试题卡片展示
   - 可选择启用的试题属性。
   - 支持拖拽排序，决定试题列表卡片上的属性展示顺序。
   - 展示文案默认使用属性名称。
   - 知识点选题、章节选题等试题列表共同消费该配置。

6. 试题列表筛选
   - 可选择启用的试题属性作为筛选项。
   - 支持拖拽排序，决定试题列表上方筛选区的属性筛选顺序。
   - 筛选项文案默认使用属性名称。
   - 知识点选题、章节选题等试题列表共同消费该配置。

7. 知识树节点展示
   - 可选择启用的知识点属性。
   - 支持拖拽排序，决定知识树或章节树节点上属性标识的展示顺序。
   - 展示文案默认使用属性名称。
   - 展示形式是伴随节点出现的标识或说明，例如“2025 首次考查”。
   - 树节点内容读取知识体系数据，节点属性值读取知识体系模块中的绑定结果。

8. 专题树节点展示
   - 可选择启用的专题属性。
   - 支持拖拽排序，决定专题树节点上属性标识的展示顺序。
   - 展示文案默认使用属性名称。
   - 树节点内容读取专题体系数据，节点属性值读取专题体系模块中的绑定结果。

## 交互设计

页面建议使用 PC 端 Tab 结构：

- 顶部：年级、学科筛选。
- 一级 Tab：属性定义 / 使用设置。
- 属性定义 Tab：左右布局。
  - 左侧为属性定义列表，可按“试卷属性 / 试题属性 / 知识点属性 / 专题属性”分组或切换。
  - 右侧为当前属性的枚举值管理。
- 使用设置 Tab：按“试卷上传 / 试卷卡片展示 / 试卷列表筛选 / 试题打标 / 试题卡片展示 / 试题列表筛选 / 知识树节点展示 / 专题树节点展示”展示。

属性定义区只出现定义相关内容。使用设置区只出现场景相关内容。用户选中某个使用场景时，只能看到该场景允许使用的属性类型。知识点属性和专题属性被选中时，右侧展示普通枚举值维护；同时提供跳转入口，去知识体系或专题体系模块维护节点与属性值的绑定。

## 数据模型建议

现有 `TagCategory` 可继续作为属性定义主体，但需要调整语义：

- `target` 收敛为 `paper`、`question`、`knowledge` 或 `topic`。
- `tags` 表示属性的枚举值。试卷属性、试题属性、知识点属性和专题属性都使用 `tags` 维护可选值。
- `status` 表示属性启用状态。
- `sort` 可新增到属性层，用于属性定义排序。
- `code` 保留为内部字段，由系统生成，不在主界面展示。
- 知识点属性值与知识树节点的绑定关系不放在属性定义中，由知识体系模块维护。
- 专题属性值与专题树节点的绑定关系不放在属性定义中，由专题体系模块维护。

新增或调整使用配置结构：

```ts
type AttributeUsageScene =
  | 'paperUpload'
  | 'paperCardDisplay'
  | 'paperListFilter'
  | 'questionTagging'
  | 'questionCardDisplay'
  | 'questionListFilter'
  | 'knowledgeTreeNodeDisplay'
  | 'topicTreeNodeDisplay';

interface AttributeUsageRule {
  id: string;
  attributeId: string;
  scene: AttributeUsageScene;
  enabled: boolean;
  required?: boolean;
  sort: number;
}
```

消费端按场景读取规则：

- 上传页读取 `paperUpload`。
- 成品套卷等试卷列表卡片读取 `paperCardDisplay`。
- 成品套卷等试卷列表筛选区读取 `paperListFilter`。
- 打标页读取 `questionTagging`。
- 知识点选题和章节选题的试题列表卡片读取 `questionCardDisplay`。
- 知识点选题和章节选题的试题列表筛选区读取 `questionListFilter`。
- 知识树节点读取 `knowledgeTreeNodeDisplay`。
- 专题树节点读取 `topicTreeNodeDisplay`。

## 消费端规则

上传页：

- 只读取启用的试卷属性。
- 按 `paperUpload.sort` 展示。
- 对 `required` 为 true 的属性执行必填校验。

打标页：

- 只读取启用的试题属性。
- 按 `questionTagging.sort` 展示。
- 对 `required` 为 true 的属性执行必填校验。

试卷卡片展示：

- 只读取启用的试卷属性。
- 按 `paperCardDisplay.sort` 在试卷列表卡片上展示。
- 属性名称作为默认展示文案。
- 枚举值按属性定义中的枚举值顺序展示。
- 成品套卷等试卷列表共同消费该配置。

试卷列表筛选：

- 读取启用的试卷属性作为筛选项。
- 按 `paperListFilter.sort` 展示在试卷列表上方筛选区。
- 属性名称作为默认筛选文案。
- 枚举值按属性定义中的枚举值顺序展示。
- 成品套卷等试卷列表共同消费该配置。

试题卡片展示：

- 读取启用的试题属性。
- 按 `questionCardDisplay.sort` 在试题列表卡片上展示。
- 属性名称作为默认展示文案。
- 知识点选题、章节选题等试题列表共同消费该配置。

试题列表筛选：

- 读取启用的试题属性作为筛选项。
- 按 `questionListFilter.sort` 展示在试题列表上方筛选区。
- 属性名称作为默认筛选文案。
- 知识点选题、章节选题等试题列表共同消费该配置。

知识树节点展示：

- 只读取启用的知识点属性。
- 按 `knowledgeTreeNodeDisplay.sort` 展示。
- 属性名称作为默认展示文案。
- 属性值以标识或说明形式伴随知识树、章节树节点展示。
- 树节点和层级读取知识体系模块的数据，节点属性值读取知识体系模块中的绑定结果。

专题树节点展示：

- 只读取启用的专题属性。
- 按 `topicTreeNodeDisplay.sort` 展示。
- 属性名称作为默认展示文案。
- 属性值以标识或说明形式伴随专题树节点展示。
- 树节点和层级读取专题体系模块的数据，节点属性值读取专题体系模块中的绑定结果。

## 迁移策略

当前页面已有的 `contentCompletion`、`tagging`、`frontDisplay` 规则需要迁移为新的使用场景：

- `contentCompletion` 且属性为试卷属性，迁移为 `paperUpload`。
- `tagging` 且属性为试题属性，迁移为 `questionTagging`。
- `frontDisplay` 且属性为试卷属性，迁移为 `paperCardDisplay`。
- 原 `displayRule.filterable` 为 true 时，额外迁移为 `paperListFilter`。
- 试题卡片展示和试题列表筛选是新增场景，需要从试题属性中人工选择启用。
- 现有知识点树和专题树节点不迁移为枚举值。仅需为知识点属性和专题属性补充对应枚举值，例如目标分类、重难点、考频。
- 不符合新业务矩阵的旧配置在前端不再展示。

## 验收标准

1. 属性定义区不再出现上传、打标、前台展示、筛选、必填配置。
2. 使用设置区按八个业务场景展示，且每个场景只出现允许使用的属性类型。
3. 试卷属性无法配置打标、试题卡片展示或试题列表筛选，试题属性无法配置上传、试卷卡片展示、试卷列表筛选、知识树节点展示或专题树节点展示。
4. 知识点属性不能作为试卷属性或试题筛选项使用，只能作为知识树、章节树节点的伴随展示信息。
5. 专题属性不参与知识点选题或章节选题筛选，只服务专题树节点展示。
6. 试卷卡片展示、试卷列表筛选、试题卡片展示、试题列表筛选是独立用途。
7. 前台名称默认使用属性名称，主流程不要求重复填写。
8. 属性和枚举值均支持手动排序。
9. 枚举值列表使用克制的文本样式，不使用彩色标签。
10. 知识点属性和专题属性在枚举值列表中维护属性取值，但不在枚举值列表中重复维护树节点。
11. 页面不再暴露属性编码、取值字段、字段类型、控件类型作为主流程字段。

## 实施顺序

1. 调整属性设置页的信息架构，拆分属性定义和使用设置。
2. 调整 mock 与服务类型，使属性定义和使用规则可以分开维护。
3. 保留现有属性和枚举值增删改能力。
4. 新增使用设置的八个场景配置。
5. 接入上传页读取试卷上传配置。
6. 接入打标页读取试题打标配置。
7. 为试卷卡片展示和试卷列表筛选预留消费接口。
8. 为试题卡片展示、试题列表筛选、知识树节点展示和专题树节点展示预留消费接口。
