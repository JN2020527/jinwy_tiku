# 资源资产线栏目 V1.8 原型说明

## 运行与入口

```bash
npm run dev
```

- 资产中心：`/preparation/asset-center`
- 在线新建学案：`/combination-production/new?subject=:subject&type=studyGuide`
- 知识块：`/preparation/knowledge-blocks`
- 正式学案预览/编辑：`/combination-production/revision/:resourceId`
- 栏目维护：`/preparation/subject-columns`
- 知识树：`/preparation/knowledge-tree`

项目为纯前端原型。资源资产页面统一通过 `src/services/resourceAssets.ts` 与 `mock/resourceAssets.ts` 交互；`mock/resourceAssetsStore.ts` 保存资产、学案结构、知识块和引用关系。栏目维护继续使用 `subjectColumns` service/mock，知识树继续使用 `tagSystem` service/mock；mock 间读取共享状态，避免注册栏目、知识树来源节点和学案引用数量互相漂移。

## 设计说明

### 资产中心

- 页面只管理资产本体，不展示资源树归属、上架、归档、版本或操作账本。
- 顶部固定三个入口：“上传附件”“新建学案”“新建作业”。新建学案进入在线结构编辑，可保存草稿或发布为正式学案。
- 上传入口只接收附件；附件由扩展名自动识别类型，`.docx` 不转换为学案。
- 列表字段固定为名称、类型、状态、原文件名、更新时间和操作；挂载与引用数量只在修改确认或删除阻断时出现。
- 行内直接暴露继续处理、查看、改名、替换等高频操作；删除收进“更多”并二次确认。

### 学案在线创建

- 学案结构必须从一级开始逐级建立，不允许跳级；每个分支可在任意层级结束。
- 各层级新增栏目时可选择注册栏目，也可填写仅属于当前学案的自定义栏目；自定义栏目不回写栏目维护。
- 自定义栏目下级仍可选择注册栏目，但只展示适用于目标层级的注册栏目。
- 选择知识树来源栏目后，必须再选当前学科知识树末级节点，并同时保存注册栏目 ID 与节点 ID。
- 左侧栏目导航只维护栏目新增、调整和删除；右侧连续正文只维护内容新增和栏目项删除。添加内容时选择栏目内容或四类知识并编写正文；单一、方法、例题类不重复选择知识点，综合类需从当前学科知识树中手动选择至少两个末级知识点。保存草稿只保存结构、内容及综合类手选范围，不创建正式知识块或写入知识点关系；发布为正式学案时，单一、方法、例题类自动关联所属考点栏目节点，综合类按手选结果写入，并将知识类内容写入正式知识块。试题引用的添加规则等待后续确认。

### 知识块

- 列表完整展示富文本，不增加名称或摘要。
- 学科在列表选择，新建/编辑抽屉中锁定；单一、方法、例题类只能关联一个末级节点，综合类至少关联两个末级节点并可继续多选。
- 选择知识树父节点时，mock 收集其后代末级节点后筛选知识块。
- 点击引用学案先进入只读预览；编辑需要再次显式触发。
- 被引用知识块修改前显示影响数量；关系变化会使既有引用范围失效时阻止保存；被引用时禁止删除。

### 正式学案组合编辑器

- `/revision/:resourceId` 沿用旧路由，但不再表示“创建修订版本”，而是维护同一正式学案 ID。
- 页面默认只读预览；显式点击“编辑正式学案”后开放结构操作。
- 一级至四级统一支持注册栏目和当前学案自定义栏目；知识树来源统一通过末级节点 ID 展示当前名称。
- 左侧支持栏目新增、删除、同层排序和移动到其他上级栏目；右侧支持栏目原生内容、四类知识内容新增和栏目项删除，不混放栏目操作。知识内容在保存学案时统一建立知识块和考点关系；已有知识块选择与试题引用仍等待后续规则。
- 保存前展示资源节点、平台模板和教师任务影响数量；失败时正式内容不变，页面本次编辑保留。

### 栏目与知识树

- 栏目维护使用一张表管理栏目定义；一条栏目记录可以同时选择多个适用层级，注册栏目之间不保存父子关系，同学科栏目名称唯一。
- 栏目记录类型和数据来源；知识树来源只能为知识型，同学科同层级最多一个。创建后允许编辑名称和适用层级，类型与数据来源不可修改；已被学案引用的适用层级不可取消，被学案引用时阻止删除。
- 编码规则归属“学科 + 层级”，每个层级可选择不编码、“中文数字 + 顿号”“中文数字 + 圆括号”或“阿拉伯数字 + 英文句点”。同一级栏目在各自直接父栏目下重新编号；各层级的栏目顺序分别维护。
- 知识树结构守卫读取知识块关系和学案知识树来源节点引用。存在任一关系时禁止新增子节点、接收拖入节点而变非末级或删除，并分别显示数量。
- `/preparation/resource-tree` 与 `/tag-system/knowledge` 保持原页面和数据域。

## Mock fixture

- 数学正式学案“有理数单元学案”包含两项资源节点挂载、一项平台模板引用和三项教师任务引用，用于修改影响确认与删除保护。
- 数学草稿“整式复习学案”用于验证草稿引用也计入栏目删除保护。
- 数学知识块覆盖四种类型，既有被引用和无引用记录。
- 生物知识树与栏目可保持空状态，用于验证空页面入口。
- fixture 只用于原型验收，不代表生产数据、接口或存储设计。

## 假设与待确认

- [ ] 从已有知识块选择引用、试题型栏目选择试题的具体交互等待“在线编辑学案”后续需求；当前知识类入口用于新建知识块并加入栏目。
- [ ] 文件大小上限由系统配置提供；原型只展示“以系统配置为准”，不编造数值。
- [ ] mock 使用内存状态，刷新开发服务后恢复 fixture；不代表生产持久化方案。
- [ ] 作业不使用学案栏目结构，不构成注册栏目使用关系。
