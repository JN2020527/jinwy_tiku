# 资源资产线 V0.3 原型说明

## 运行与入口

```bash
npm run dev
```

- 资产中心：`/preparation/asset-center`
- 成品学案拆分结果：`/preparation/asset-center/study-guide/:draftId/split`
- 知识块：`/preparation/knowledge-blocks`
- 正式学案预览/编辑：`/combination-production/revision/:resourceId`
- 栏目维护：`/preparation/subject-columns`
- 知识树：`/preparation/knowledge-tree`

项目为纯前端原型。资源资产页面统一通过 `src/services/resourceAssets.ts` 与 `mock/resourceAssets.ts` 交互；`mock/resourceAssetsStore.ts` 保存资产、学案结构、知识块和引用关系。栏目维护继续使用 `subjectColumns` service/mock，知识树继续使用 `tagSystem` service/mock；mock 间读取共享状态，避免栏目、学案三级考点和知识块引用数量互相漂移。

## 设计说明

### 资产中心

- 页面只管理资产本体，不展示资源树归属、上架、归档、版本或操作账本。
- 顶部固定三个入口：“上传资源”“新建学案”“新建作业”。后两者按 V0.3 只保留可见入口，点击仅解释后续能力，不创建草稿。
- “上传资源”区分成品学案与附件。两者继承当前学科；附件由扩展名自动识别类型。
- 列表字段固定为名称、类型、状态、原文件名、更新时间和操作；挂载与引用数量只在修改确认或删除阻断时出现。
- 行内直接暴露继续处理、查看、改名、替换等高频操作；删除收进“更多”并二次确认。

### 成品学案拆分

- `.docx` 解析使用四个 fixture 表达有效拆分、批量格式错误、试题型跳过后为空、综合类无三级考点；不假装完成真实 Word 解析。
- 成功后创建草稿并进入独立拆分页。左侧结构只读，右侧按内容块完整展示富文本。
- 草稿只支持编辑、删除内容块。每次调整调用自动保存；删除后 mock 清理空结构并重算综合类候选知识点。
- 最终保存把学案、栏目项、新知识块和关系一起转为正式；失败保持草稿，不产生部分正式数据。

### 知识块

- 列表完整展示富文本，不增加名称或摘要。
- 学科在列表选择，新建/编辑抽屉中锁定；单一、方法、例题类只能关联一个末级节点，综合类可多选。
- 选择知识树父节点时，mock 收集其后代末级节点后筛选知识块。
- 点击引用学案先进入只读预览；编辑需要再次显式触发。
- 被引用知识块修改前显示影响数量；关系变化会使既有引用范围失效时阻止保存；被引用时禁止删除。

### 正式学案组合编辑器

- `/revision/:resourceId` 沿用旧路由，但不再表示“创建修订版本”，而是维护同一正式学案 ID。
- 页面默认只读预览；显式点击“编辑正式学案”后才开放结构和栏目项操作。
- 一级/四级读取当前注册栏目，二级由当前学案自由命名，三级读取知识树末级节点。
- 支持结构新增、删除、跨父级移动和同组上移/下移；知识块引用可更换，栏目原生内容可编辑。
- 综合类本次知识范围只显示源知识块关系与当前学案三级考点的交集，并默认全选交集。
- 保存前展示资源节点、平台模板和教师任务影响数量；失败时正式内容不变，页面本次编辑保留。

### 栏目与知识树

- 栏目维护只注册一级、四级；同学科名称全局唯一。被学案使用的栏目可改名排序，禁改类型和删除；被使用四级禁调一级归属。
- 知识树结构守卫同时读取知识块关系和学案三级考点项引用。存在任一关系时禁止新增子节点、接收拖入节点而变非末级或删除，并分别显示数量。
- `/preparation/resource-tree` 与 `/tag-system/knowledge` 保持原页面和数据域。

## Mock fixture

- 数学正式学案“有理数单元学案”包含两项资源节点挂载、一项平台模板引用和三项教师任务引用，用于修改影响确认与删除保护。
- 数学草稿“整式复习学案”用于验证退出后继续和多草稿独立保存。
- 数学知识块覆盖四种类型，既有被引用和无引用记录。
- 生物知识树与栏目可保持空状态，用于验证空页面入口。
- fixture 只用于原型验收，不代表生产数据、接口或存储设计。

## 假设与待确认

- [ ] 真实 `.docx` 对段落、编号、表格、图片、公式、页眉页脚的解析与 wangEditor 兼容性待技术验证；本原型只验证产品交互和状态边界。
- [ ] 文件大小上限由系统配置提供；原型只展示“以系统配置为准”，不编造数值。
- [ ] mock 使用内存状态，刷新开发服务后恢复 fixture；不代表生产持久化方案。
- [ ] 作业本期只有资产中心展示和新建入口，不形成草稿、不进入组合编辑器。
- [ ] 浏览器交互和视觉验收不属于当前默认验收方式；本轮按文档、源码与工程构建对照验收。
